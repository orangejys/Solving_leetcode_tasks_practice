## №57 · Insert Interval

**Сложность:** Medium  
**[Условие на LeetCode](https://leetcode.com/problems/insert-interval/)** · **[Моё решение](57_%20Insert_Interval.py)**

### Условие

Дан список непересекающихся интервалов `intervals`, упорядоченных по левой границе, и новый интервал `newInterval`.
Вставь новый интервал, объединив его со всеми пересекающимися интервалами. Результат должен оставаться отсортированным и не содержать пересечений.

Интервалы включают свои границы: `[1, 3]` и `[3, 5]` пересекаются. Можно вернуть новый список.

### Пример

```python
intervals = [[1, 2], [3, 5], [6, 7], [8, 10], [12, 16]]
newInterval = [4, 8]
# Результат: [[1, 2], [3, 10], [12, 16]]
```

Новый интервал объединяется с `[3, 5]`, `[6, 7]` и `[8, 10]`.

### Ограничения

- От 0 до 10⁴ исходных интервалов.
- Каждый интервал содержит две границы: `0 ≤ start ≤ end ≤ 10⁵`.
- Исходные интервалы отсортированы и не пересекаются.
- Для нового интервала также выполняется `0 ≤ start ≤ end ≤ 10⁵`.

### Идея моего решения

Два бинарных поиска находят границы участка для объединения:

1. `lower_bound` — первый интервал, правая граница которого не меньше начала нового.
2. `upper_bound` — первый интервал, левая граница которого больше конца нового.
3. Если участок непустой, расширяем новый интервал до крайних границ этого участка.
4. Соединяем левую часть списка, объединённый интервал и правую часть.

**Время:** `O(n)` с учётом срезов и создания результата; поиск границ — `O(log n)`.  
**Память:** `O(n)` на результат и промежуточные списки.

## №387 · First Unique Character in a String

**Сложность:** Easy  
**[Условие на LeetCode](https://leetcode.com/problems/first-unique-character-in-a-string/)** · **[Моё решение](387_First_Unique_Character_in_a_String.py)**

### Условие

Найди в строке `s` первый символ, который встречается ровно один раз. Верни его индекс, считая с нуля. Если такого символа нет, верни `-1`.

### Примеры

```python
s = "leetcode"      # Результат: 0 — символ 'l'
s = "loveleetcode"  # Результат: 2 — символ 'v'
s = "aabb"          # Результат: -1
```

### Ограничения

- Длина строки — от 1 до 10⁵.
- Строка состоит из строчных английских букв.

### Идея моего решения

Сначала считаем количество вхождений каждого символа в словаре `count_map`.
Затем повторно проходим строку слева направо и возвращаем индекс первого символа с частотой `1`.
Если весь второй проход завершился без ответа, возвращаем `-1`.

**Время:** `O(n)`, где `n` — длина строки.  
**Память:** `O(k)`, где `k` — количество различных символов. По условию `k ≤ 26`, поэтому дополнительная память — `O(1)`.

## №821 · Shortest Distance to a Character

**Сложность:** Easy  
**[Условие на LeetCode](https://leetcode.com/problems/shortest-distance-to-a-character/)** · **[Моё решение](821_Shortest_distance_to_a_character.py)**

### Условие

Даны строка `s` и символ `c`, который гарантированно присутствует в ней.
Для каждой позиции строки найди расстояние до ближайшего вхождения `c`. Верни список расстояний той же длины, что и строка.

Расстояние между позициями `i` и `j` равно `abs(i - j)`.

### Примеры

```python
s = "loveleetcode"
c = "e"
# Результат: [3, 2, 1, 0, 1, 0, 0, 1, 2, 2, 1, 0]

s = "aaab"
c = "b"
# Результат: [3, 2, 1, 0]
```

### Ограничения

- Длина строки — от 1 до 10⁴.
- Строка и символ `c` содержат только строчные английские буквы.
- В строке есть хотя бы одно вхождение `c`.

### Идея моего решения

Первый проход слева направо записывает расстояния до последнего встреченного `c`.
Второй проход справа налево сравнивает их с расстояниями до ближайшего `c` справа и оставляет минимум.

Начальные значения `last_include` обозначают далёкие позиции вне строки: они не дают отсутствующему вхождению повлиять на ответ. В текущем коде их модуль больше максимальной длины строки.

**Время:** `O(n)`.  
**Память:** `O(n)` на список ответа; помимо него — `O(1)`.
